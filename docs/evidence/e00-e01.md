## E04 plugin manager evidence

- Independent `file://` Plugin Manager window with a dedicated CommonJS
  sandbox preload (`plugin-manager.cjs`) exposing only the typed
  `insuremoPlugins` API; every IPC handler re-authorizes the exact window,
  main frame, and URL before acting, and a non-manager window loading the
  same preload receives `forbidden` for `plugin:list` (verified in the E04
  Electron test).
- Main-process native dialogs return one-time capability ids for tgz and
  local directory payloads; absolute paths never reach the renderer. A
  capability is consumed (deleted) on first use, so replayed capability ids
  are rejected (`unknown or already-consumed capability`), and operation
  failures are redacted before reaching the renderer (known install bases
  become `<redacted>`, remaining user/tmp/home paths become `<path>`).
- Strict spec protocol: npm name@exact-version, alias
  `<alias>@npm:<target>[@version]`, and allowlisted git URLs
  (https/git+https/ssh). Options injection (`--`, leading `-`, NUL) is
  rejected before pnpm runs; pnpm verbs are fixed (add/remove) with
  `shell:false`.
- Every operation is transactional: staging copy of the live profile →
  pnpm against staging → reconcile with pre-operation dependency snapshot →
  intent-journal two-phase activation → provenance record (spec digest,
  resolved name/version, lockfile integrity SHA256, tgz SHA256).
- Rollback restores the previous verified generation
  (`profiles/web.prev`) through an intent-journal-covered destructive
  window (`intent_activate` recovery semantics complete the rollback if
  the process dies mid-operation) and leaves the journal `committed`.
- Plugin Manager IPC handlers register once per process against the
  active service, so closing and reopening the window never double-
  registers a channel (verified by a real open-close-open probe).
- Real E04 Electron test (out/ build): install test bundle via capability →
  plugin listed in the window via the real preload → remove via the real
  preload → plugin gone; non-manager window forbidden.
  `E04_WINDOW_RESULT {"ok":true,"detail":"{\"install\":true,\"listedBefore\":true,\"removedOk\":true,\"goneAfter\":true,\"reopenListOk\":true,\"replayRejected\":true}"}`
  (plus a non-manager-window forbidden probe in the same run).
